# Changelog

## 0.2.0

Первая публикация после **0.1.15** (npm, 03.10.2025). Между ними — 196 коммитов
за 10 месяцев, с 14.10.2025 по 12.08.2026.

Версия минорная, а не патч: таблица переехала на другой движок, а форк PrimeVue
DataTable удалён — это ломающее изменение для тех, кто на него опирался.

### Таблица переехала на TanStack

`TanTable` стал движком по умолчанию, форк PrimeVue DataTable **удалён**. Что это дало:

- **виртуальный скролл** с корректным пересчётом высот при сортировке, раскрытии
  строк и сбросе кэша;
- **автоподгонка ширин колонок** к контейнеру, ручной ресайз (с отключением автофита),
  выбор показываемых колонок и настройка ширины через попап у шестерёнки;
- **закреплённая колонка действий** (`actions_frozen: right/left`) и sticky-заголовки,
  в том числе при выключенном вертикальном скролле.

### Редактирование ячеек

- inline по клику и попап `EditField` по двойному клику; `contenteditable` вместо `input`;
- **выделение диапазона ячеек как в Excel** с суммированием (скрытые фильтром строки
  игнорируются);
- Excel-подобное автодополнение в текстовых ячейках;
- boolean переключается кликом без входа в режим правки, у дат — инлайн-календарь;
- горячие клавиши: `ctrl+enter` — переход в заданную колонку соседней строки;
- **undo/redo** для CRUD с восстановлением скролла, фильтров и сортировки.

### Фильтры

- колоночные фильтры: серверные и клиентский чеклист, с разделением в интерфейсе
  («Фильтр базы» / «Фильтр браузера») и подсказкой, что клиентский работает
  в пределах страницы;
- фильтр по пустой дате и чекбокс «(Пусто)», `datetime` со своим набором режимов
  и полем `datetime-local`;
- булевы значения в чеклисте показываются как «Да/Нет»;
- фильтры из URL: `?filters={...}`, с поддержкой namespace таблицы (для `PVTabs`)
  и полного объекта с `constraints`/`matchMode`.

### Файлы и документы

- тип ячейки **file**: превью, выбор через браузер файлов, диалог с картинкой;
- **съёмка с камеры** (`PhotoCapture`) и загрузка прямо из ячейки;
- браузер файлов: открытие папки текущего файла, навигация по дереву, мобильный
  bottom-sheet;
- многостраничный снимок документа в PDF.

### Данные без моргания

- `applyRowsDelta` — точечное обновление строк вместо полной перезагрузки,
  с корректными подписями автокомплитов (в том числе для только что вставленной строки)
  и сохранением раскрытых дочерних строк;
- диалог **версий строки** (`RowVersionsDialog`) с откатом к `data_before`;
- события `rows-loaded` для родительских компонентов.

### Мобильный режим

- `TanMobileList` — карточки вместо таблицы, с шаблонами и `data_fields`.

### Прочее

- объект в текстовом поле показывается читаемым JSON, а не `[object Object]`;
- `PVMultiAutoComplete` в экспорте; автокомплит продукции показывает путь по категориям;
- `row_setting.cells[field]` — класс и стиль на конкретную ячейку;
- `row_print` и `PVPrintAction` в строке, компактный режим;
- `select_from_json` и `dynamicSelects` для JSON-таблиц;
- внешние row-экшены пробрасываются через `inject`, сортировка по `order`;
- ленивая загрузка UMD-компонентов (`component-loader`) без повторных запросов
  за отсутствующими.
